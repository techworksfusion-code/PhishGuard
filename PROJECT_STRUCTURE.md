deployment configuration. The Android project is generated by Capacitor and
then extended with the native SMS plugin.

## Responsibilities

- `backend/src/analyzer.js` applies the URL rules in `rules.json`.
- `backend/src/routes/` exposes the check-link endpoint and any future API
  routes; per the privacy requirements, recent checks remain on the device.
- `backend/src/services/` contains Gemini integration and risk-result handling.
- `frontend/src/App.jsx` contains the responsive preview screens and local demo
  link analyzer. `frontend/src/styles.css` defines the mobile and desktop UI.
- The current frontend includes Home, Inbox, Scan, Activity, Profile, link
  results, message details, and sample settings screens. Sample content is
  illustrative; SMS access and server integration are not implemented yet.
- `frontend/android/` is a Capacitor-generated Android project. Its native SMS
  receiver sends extracted links only; message text and sender numbers stay on
  the device.
- `deployment/` contains VPS process-manager and Cloudflare Tunnel configuration.
- `.env.example` files document required settings; real credentials belong in
  local environment files and must not be committed.

The backend, deployment, and native Android portions remain planned scaffold
areas. The React frontend can be run locally using the commands in
`docs/README.md`.
